Getting Started

Upload a CSV block model or assay export featuring spatial coordinates (X, Y, Z), grade variables (e.g. Au, Cu, Ni), and domain categories to generate real-time grade-tonnage curves.

Regular, sub-blocked and variable-thickness models are all supported. Each axis is sized independently — a fixed size, a per-block size column, or a from/to pair such as ZMAX − ZMIN — so a model with fixed X/Y and a varying Z is measured correctly. Size columns and extent pairs are detected automatically; a uniform axis is inferred from the coordinate spacing and can be overridden.
