Getting Started

Upload a CSV block model or assay export featuring spatial coordinates (X, Y, Z), grade variables (e.g. Au, Cu, Ni), and domain categories to generate real-time grade-tonnage curves.

Regular and sub-blocked models are both supported. If the file carries per-block dimension columns they are detected automatically; otherwise the parent cell size is inferred from the coordinate spacing and can be overridden.
